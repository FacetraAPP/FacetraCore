# Bundled VegaLite

Vega 6.4.0 and Vega-Lite 6.5.0 compile declarative specs and render SVG offline. External resources are blocked. chart.scripts is not supported; Vega expressions retain their native declarative semantics.

Vendor distributions are unmodified. Licenses are retained beside the bundles.
