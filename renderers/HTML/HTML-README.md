# Bundled HTML

Mustache.js 4.2.0 supplies escaped placeholders, sections and lists. Authored HTML and CSS render in a sandboxed iframe with scripts and network disabled. option.js and chart.scripts are not supported.

Vendor distributions are unmodified. Licenses are retained beside the bundles.
